Architecture: a framework-independent race coordinator composes two existing playback controllers. Only the coordinator schedules ticks; it never calls lane.play(). Each tick advances unfinished lanes once, records frozen integer positions {left,right}, and publishes both lane views atomically. Cached race navigation restores these pairs, not independent cursor decrements. No snapshots are duplicated in race history.
